# Bunuelos_TuRedondito

Proyecto de forecasting de demanda para Bunuelos SAS.

## Estructura
- `.agent/`: Reglas, habilidades y workflows.
- `src/`: Código fuente.
- `tests/`: Pruebas unitarias e integración.
- `docs/`: Documentación del proyecto.
- `data/`: Datos (gestionados por DVC).
- `scripts/`: Utilidades operativas.
