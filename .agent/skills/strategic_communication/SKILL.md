# Skill: Storytelling y Visualización Estratégica (Wow Factor)

Esta habilidad permite al agente actuar como el puente entre la complejidad algorítmica y la toma de decisiones gerencial de **Bunuelos SAS**.

## 🧠 Capacidades Principales

1.  **Traducción de Métricas**: Convierte el lenguaje de ciencia de datos a lenguaje de negocio (Kit de masa, fritura diaria, mermas).
2.  **Síntesis Ejecutiva**: Destila hallazgos en "Puntos de Poder" y "Verdades Críticas" siguiendo las [Communication Rules](../../rules/communication_rules.md).
3.  **Interpretación Visual**: Analiza gráficas en `docs/artifacts/figures/` para extraer historias (ej. validación de estacionalidades o anomalías en promociones).
4.  **Auditoría Estética**: Garantiza que todo documento cumpla con el estándar visual "Bunuelos Premium".

## 🛠️ Procedimiento de Operación

1.  **Validación de Contexto (SSOT)**: Consulta el `index.md` para asegurar coherencia con el estado oficial de la fase.
2.  **Análisis de Resultados**: Recolecta evidencia técnica.
3.  **Análisis Visual**: Lee visualizaciones para extraer hallazgos narrativos.
4.  **Redacción**: Genera `docs/executive/phase_XX_executive_latest.md` siguiendo el estándar "Cero Código".
5.  **Triple Persistencia**: Asegura copia local, histórica y mención de éxito en Supabase si aplica.

## ⚠️ Restricciones Críticas
- **PROHIBIDO** mostrar código o nombres de librerías.
- **PROHIBIDO** usar términos ML sin traducción de negocio.
- **OBLIGATORIO** incluir recomendaciones para cada "Verdad Crítica".
