# Habilidad: Lessons Learned Management (PM)

Capacidad para capturar, categorizar y aplicar el conocimiento derivado de la experiencia del proyecto.

## Capacidades

1.  **Reflexión Crítica**: Analizar el historial de conversación y los resultados para identificar patrones de éxito o fallo.
2.  **Análisis de Causa Raíz**: Utilizar técnicas como los "5 Porqués" para entender el origen de las desviaciones.
3.  **Documentación Estructurada**: Mantener el `lessons_learned_log.md` con entradas claras y accionables.
4.  **Transferencia de Conocimiento**: Incorporar aprendizajes previos en la planificación de nuevas fases o tareas.

## Directrices de Operación

- **Fase de Cierre**: Activar esta habilidad automáticamente al finalizar una fase.
- **Narrativa de Mejora**: Redactar hallazgos como oportunidades de optimización.
- **Trazabilidad**: Relacionar lecciones con IDs de requerimientos `[REQ]` o tareas `[TSK]` cuando aplique.
